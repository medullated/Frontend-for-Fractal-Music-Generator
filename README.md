# Fractal Music Generator

Веб-интерфейс для генератора музыки на основе фракталов.

Функция генерации фрактала и музыки отсутствует в этом проекте.

## Возможности

- выбор типа фрактала: L-System, Mandelbrot, Julia;
- выбор настроения мелодии;
- выбор звукового эффекта;
- настройка длительности и BPM;
- валидация введённых данных;
- отправка параметров на Flask backend через `fetch`;
- отображение сгенерированного изображения;
- интерактивные карточки с CSS-анимациями и визуальными состояниями.

## Стек

- HTML5
- CSS3
- JavaScript
- Python
- Flask
